# Metrics — Quote-Escaping + Isolation Prompt Fixes (Config B)

Full report: `claude/reports/report_3_20260824-121757.md`. Scope: same 3 scenarios as the
baseline, 25 scoreable prompts / 63 parameters.

| Metric | Result |
|---|---|
| Function name accuracy | 24/25 = **96%** (unchanged) |
| Parameter accuracy | 61/63 = **97%** (up from 92%) |

An A/B/C test of two prompt-template changes: an explicit "extract only what's relevant to the
current parameter" rule vs. a second few-shot example demonstrating isolating one quoted fragment
out of a longer, multi-clause sentence. The rule alone did nothing measurable; the example alone
(Config B) fixed the over-capture regressions (a product review swallowing surrounding text, a
message including its own recipient clause) plus an unrelated empty-string case as a side effect,
at the cost of reintroducing the empty-greeting regression. Net +3 parameters fixed for -1
reintroduced. Config B (rule dropped, example kept) was the version carried forward.
